# Diamond Restaurants — Public Website Preview

This repository contains the edited public-facing Home, Menu and App pages from the supplied Firebase-ready snapshot.

## UX changes in this preview
- Home: clearer primary/secondary CTA hierarchy and calmer typography/text casing.
- Home: footer heading hierarchy improved without changing the existing admin/editor hooks.
- Menu: sticky category navigation, stronger section headings, consistent order buttons, and support for real item images when image data exists.
- App: equal-height cards, bottom-aligned actions, distinct cart icon for the store, and normalized button/icon shapes.
- Local wget query-string filenames were normalized for clean Git hosting.

## Admin preservation
The supplied ZIP did not contain the admin application files. No admin/editor code or admin hooks in the supplied files was removed or intentionally changed. Do NOT use this public-only snapshot as a complete replacement for a hosting site that also contains a separately hosted admin application until the original admin files are merged back in.
